# Progress screenshots

A small gallery showing how Hunter's Eye grew on the way to v1.000 (the MVP).
Screenshots are taken now and then by sessions on Zel's machine when a feature or
a milestone is plainly visible on screen.

## Rules

- **Budget:** a few dozen, never more than ~100 by v1.000. Roughly one per feature
  (debug panel, overlay boxes, OCR labels, control panel, Pindle run...), plus one per
  genuine milestone. If a newer shot shows the same feature better, replace the old one
  only when the old one no longer shows anything historically interesting.
- **Only when it is obvious:** the achievement must be visible in the image itself
  without explanation.
- **Filename:** `YYYY-MM-DD_short-feature-name.png` (lowercase, hyphens). PNG, cropped
  to what matters; keep each under ~1 MB.
- **Index:** every image gets one row below, newest at the bottom, in the same commit.
- Real captures only, never mockups. No personal info (account names, other windows).
